# Sourced

Accurate Half-Life and Quake movement for Minecraft on NeoForge.  

Four presets: HL1 Movement on Source, Half-Life 1, Half-Life 2 with accelerated back hopping, and the original quake-style movement.   

This mod works fine if installed only on the client, but in order to prevent fall damage from slowing down the player it must be installed on the server too. A server running Sourced requires every player to have the same version of it installed. Players can toggle the mod individually in the settings, or using the keybind.

Requires [Kotlin for Forge](https://modrinth.com/mod/kotlin-for-forge) and depends on [YetAnotherConfigLib](https://modrinth.com/mod/yacl).

### Features

- Half-Life and quake-style movement, four presets
- bunnyhop
- air strafing
- trimping
- sharking
- speed-gain falloff, which keeps bunnyhopping balanced in survival without flattening the feel
- speed indicator
- in-game config
- adjustable values
- keybinds to toggle the mod and cycle presets
